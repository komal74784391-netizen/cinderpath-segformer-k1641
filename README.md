# Cinderpath Segformer

Segmentation utilities released with the Cinderpath aerial-imagery model.

**Repository Status:** Released (v1.2.0, published 2026-04-27)

## Contents

- `src/cinderpath/segformer.py`
- `requirements.txt`

## Quick start

```bash
pip install -r requirements.txt
python -m cinderpath.segformer --tile tile.tif
```
